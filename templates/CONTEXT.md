# Research context

The scout and the referee read this file. Keep it short and concrete.

Optional tracks: add sections named `## Track: <name>` (one word, for example `work` or `portfolio`). Then `py loop.py night 30 <name>` or `py loop.py scout <name> ideas about <topic>` researches only that track. Each agent gets the shared sections plus that one track.

## Goals

What should the research find or build? Who would use the results?

## Topics

One topic per line. Sessions use these when you give no topic.

## Track: example

Goals, topics and rules that apply only to this track. Delete this section if you do not need tracks.

## Edge

What do you know, have or can use that most researchers do not? Free data sources, domain methods, tools.

## Rules

- Free, public data only.
- Anything else the agents must never do.
